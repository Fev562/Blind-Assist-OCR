# Blind-Assist-OCR
This project is an AI-powered tool that converts printed or handwritten text into speech and is designed to empower blind and visually impaired users. By combining OCR (Optical Character Recognition) with text to speech technology, it helps users access written information in real time which can be from books and documents.
#OPTITEXT 
A python project that uses tesseract OCR and text to speech mechanism to support blind people read a text on a image or any printed texts.
#Features
- it captures image using a computer’s camera 
- it extracts text using OCR
- it reads the text out loud 
- it works on windows with python 3.12 and required libraries
#How to run
- first install python 3.12
- install libraries 
- install OCR
- run the code
